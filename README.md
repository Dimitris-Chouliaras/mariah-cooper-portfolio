A portfolio about the artist "Mariah Cooper"

https://mariah-cooper-portfolio.netlify.app/

Netlify is primarily designed for hosting static sites and doesn't provide a backend server. The contact form isn't working if you use the link. There is a PHP file for form handling!

This project is a fully-responsive, multi-page portfolio site built to showcase the work and identity of the fictional artist Mariah Cooper. It was developed using HTML, CSS, JavaScript and PHP, and it features:

A clean, modern layout with intuitive navigation across home, portfolio/gallery, FAQ and contact pages.

CSS-based styles (including responsive media queries) to ensure that the design adapts gracefully across devices and screen sizes.

JavaScript enhancements for interactive features (e.g., handling the FAQ accordion) and PHP to process the contact form backend.

An image-rich portfolio section optimized for visual impact while maintaining fast loading times.

Semantic markup and accessibility considerations (e.g., meaningful HTML elements, use of <section> and <label for> / id pairings where applicable), applying best practices in modern front-end development.

A deployment setup (hosted via Netlify) demonstrating the full workflow from local development to live presentation.

This portfolio project not only highlights design and implementation skills in front-end web technologies, but also demonstrates my ability to structure multi-page sites, integrate form handling, and ensure cross-device compatibility—making it an ideal showcase of my readiness for front-end development roles.
